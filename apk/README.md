## 🔧 التثبيت

### 1. تفعيل التثبيت من مصادر خارجية

```
الإعدادات → الأمان → مصادر غير معروفة → تفعيل
```

### 2. تحميل وتثبيت APK

```bash
# تحميل الملف
wget https://github.com/droy-go/droy/releases/download/v1.0.0/droy-editor.apk

# تثبيت
adb install droy-editor.apk
```

### 3. فتح التطبيق

ابحث عن **"Droy Editor"** في قائمة التطبيقات

## 🎯 الاستخدام

### كتابة الكود

```droy
// مثال بسيط
~s message = "Hello from Android!"
em message
```

### تشغيل الكود

1. اكتب الكود في المحرر
2. اضغط زر **▶ تشغيل**
3. شاهد النتيجة في لوحة الإخراج

## 🐛 حل المشاكل

### مشكلة: "التطبيق لا يعمل"

**الحل:**
```
1. تأكد من تفعيل "مصادر غير معروفة"
2. أعد تحميل APK
3. أعد التثبيت
```

### مشكلة: "خطأ في التثبيت"

**الحل:**
```bash
# إلغاء تثبيت النسخة القديمة
adb uninstall com.droy.editor

# تثبيت النسخة الجديدة
adb install droy-editor.apk
```
